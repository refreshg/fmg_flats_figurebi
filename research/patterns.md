# 6 პატერნი — ინტერაქტიული ბინის ამომრჩევი პლატფორმები

**წყარო:** [competitors_1.md](competitors_1.md) (11 პროდუქტის ანალიზი)
**თარიღი:** 2026-08-21

ქვემოთ 6 განმეორებადი პატერნია, რომლებიც ბაზრის ყველა სერიოზულ მოთამაშესთან ჩნდება — თითოეული აღწერით, ვინ იყენებს და რა დასკვნა გამომდინარეობს ჩვენი პროდუქტისთვის.

## პატერნი 1 — ერთიანი 4-საფეხურიანი drill-down flow

**გენგეგმა → კორპუსი → სართული → ბინის ბარათი → lead form**

ეს არის უნივერსალური ხერხემალი. სახელები იცვლება (masterplan / site plan / Генплан; building selector / UnitView; шахматка / floor plan), ლოგიკა — არა: მომხმარებელი იწყებს მთელი კომპლექსის ხედით და თანმიმდევრულად ვიწროვდება ერთ ერთეულამდე.

| პროდუქტი | ტერმინოლოგია |
|---|---|
| 3D Flat Finder | masterplan → building → home → view & surroundings |
| Your Next Home | 360° orbit მთელ კომპლექსზე → ერთი კორპუსის orbit → ბინა |
| Vinode | ქალაქის masterplan → კორპუსი → სართული → ინტერიერი |
| Flatris | ობიექტი → კორპუსი → სექცია → სართული |
| Realty.cat / Profitbase | Генплан → корпус → шахматка → план этажа |

**ბინის ბარათის სავალდებულო მინიმუმი:** ფასი, სტატუსი (available/booked/sold), მ², ოთახები, სართული, გეგმა (2D ან 3D), ტური, PDF, lead form.

**დასკვნა:** ეს MVP-ია, არა დიფერენციატორი. ამის გარეშე პროდუქტი ბაზარზე არ ითვლება; ამით ერთით კი — არ გამოირჩევა.

## პატერნი 2 — ბაზრის ბიფურკაცია: 2D "შახმატკა" vs ნამდვილი 3D

ბაზარი მკვეთრად ორ ბანაკად იშლება და შუა ველი ცარიელია:

**(a) 2D შახმატკა-ცენტრული SaaS** — Profitbase, Flatris, Realty.cat, GRIDIX
- იაფი ($299–600/თვე ან ~20 000 ₽), თვითმომსახურე onboarding (3–5 დღე)
- ფოკუსი CRM-ზე, inventory-ზე, ანალიტიკაზე
- buyer experience — სუსტი

**(b) ნამდვილი 3D viewer-ები** — 3D Flat Finder, Your Next Home, Vinode, 3D Twin, Flat.show
- ძვირი production (Unreal Engine, არქიტექტორთა გუნდი, 1–5 კვირა build)
- გაცილებით ძლიერი buyer experience
- ხშირად quote-ზე, არა გამჭვირვალე ფასზე

**დასკვნა:** თავისუფალი ნიშა — **3D-ხარისხის flow, 2D-ის self-serve ფასად და onboarding-ის სიჩქარით.**

---

## პატერნი 3 — ორმხრივი CRM სინქი როგორც შესვლის ბილეთი

არცერთი ლიდერი არ ყიდის viewer-ს იზოლირებულად; ყველა ყიდის "viewer + CRM ეკოსისტემას". Flat.show-ის pitch პირდაპირ ასეა აწყობილი: **VISUALISE → INTERACTIFY → INTEGRATE.**

**რეგიონული გაყოფა:**
- პოსტ-საბჭოთა ბაზარი → **amoCRM, Bitrix24** (GRIDIX, Realty.cat, Profitbase, Flatris)
- დასავლეთი → **HubSpot, Salesforce** (3DFF, YNH, Vinode)
- იაფი inventory source → **Google Sheets** (Flatris, 3DFF)
- უნივერსალური → **webhooks / public API / XML ფიდები პორტალებზე**

**კრიტიკული დეტალი:** two-way sync, არა ცალმხრივი export. ფასი/სტატუსი იცვლება CRM-ში → viewer-ზე მყისიერად; lead იბადება viewer-ზე → CRM-ში კონტექსტით (რომელი ბინა, shortlist depth, comparisons, revisits).

**კომერციული სიგნალი:** 3DFF-ს CRM ინტეგრაცია ცალკე tier-ად აქვს გატანილი (€199 → €399/თვე) — ანუ ეს არის ის, რაშიც კლიენტი იხდის.

**დასკვნა:** custom ინტეგრაცია უფასოდ და სწრაფად (3DFF და YNH — ~1 კვირაში) გახდა de facto სტანდარტი. არ არის upsell — არის ვალდებულება.

## პატერნი 4 — Buyer-side ჩართულობის ინსტრუმენტების სავალდებულო ნაკრები

ერთი და იგივე 5 ფუნქცია მეორდება პრაქტიკულად ყველგან:

1. **Favourites / shortlist** (+ გაზიარება ოჯახთან ან აგენტთან)
2. **Compare** — ბინების გვერდიგვერდ შედარება
3. **ფილტრები** — სართული, ოთახები, ფართი, ორიენტაცია, ხედი, ბალკონი, ფასი
4. **PDF ბროშურა** — Vinode-ს **Dynamic PDF** აქ ყველაზე შორს მიდის: პერსონალიზებული ბროშურა სწორედ არჩეული ბინით
5. **List / Card / Grid გადართვა** — ვიზუალური და ტაბულარული ხედის ალტერნატივა

**დასკვნა:** ეს არის "table stakes" — არსებობა მოსალოდნელია, არარსებობა შესამჩნევია. დიფერენციაცია მხოლოდ შესრულების ხარისხზეა (მაგ. Dynamic PDF vs სტატიკური PDF).

## პატერნი 5 — დიფერენციაცია სივრცული "მაგიის" მომენტებით

იქ, სადაც core flow ყველას აქვს, ლიდერები ყიდიან კონკრეტულ ვიზუალურ wow-ეფექტებს:

| ეფექტი | ვინ |
|---|---|
| **ფასადზე hover-highlight** — ბინაზე გადატანისას ფასადზე ინთება ზუსტად მისი ფანჯრები | Your Next Home |
| **ბალკონის ხედი** — რეალური ხედი თითოეული ბალკონიდან 360° | 3D Flat Finder, 3D Twin (COMFORT) |
| **მზის სიმულაცია / დღე-ღამე** — განათება დღის დროის მიხედვით + orientation compass | 3D Flat Finder, 3D Twin, VisEngine |
| **Spatial filtering** — ფილტრი პირდაპირ 3D მოდელზე, არა გვერდით პანელზე | 3D Flat Finder |
| **AreaView 360 / Virtual Walk** — უბნის კონტექსტი: სკოლები, პარკები, ტრანსპორტი, ქუჩის დონე | 3D Flat Finder |
| **3D Dollhouse** — ბინის ჭრილი 3D მოდელი | 3D Flat Finder |
| **ინტერიერის სტილის switcher** | Vinode, YNH, 3D Twin |

**საერთო ლოგიკა:** ყველა ეს ეფექტი პასუხობს ერთ კითხვას, რომელსაც მყიდველი ვერ სვამს შახმატკაზე — *"რას დავინახავ ფანჯრიდან და როგორ იქნება აქ განათება?"*

**დასკვნა:** ერთი კარგად შესრულებული სივრცული ეფექტი (მაგ. ფასადზე highlight) მეტ დიფერენციაციას იძლევა, ვიდრე ხუთი ნახევრად გაკეთებული.

## პატერნი 6 — Behavioral analytics → lead scoring → ორმაგი დისტრიბუცია

**ორი განზომილება, რომელიც ერთმანეთს ავსებს:**

**(ა) ანალიტიკა როგორც პროდუქტი დეველოპერისთვის.** viewer აგროვებს event-level მონაცემებს: რომელი კორპუსი/სართული/ფასის დიაპაზონი იზიდავს ყურადღებას, რამდენმა გახსნა კონკრეტული ბინა, რამდენ ხანს, favourites/compare → **demand ranking** და დინამიური ფასწარმოქმნის საფუძველი. Vinode და YNH ამას აქცევენ **lead scoring-ად** (hot/warm/cold ქცევიდან, არა ფორმის ველებიდან). GRIDIX-ს პირდაპირ ROI-ს ჰპირდება: +40% კონვერსია, 3× უფრო სწრაფი გარიგება, −30% მოზიდვის ხარჯი.

**(ბ) ერთი build, სამი არხი.** ერთი და იგივე პროდუქტი იყიდება სამჯერ:
- **Embed** — iframe/snippet დეველოპერის არსებულ საიტზე (ერთი ხაზით — 3DFF)
- **Hosted / white-label subdomain** — custom domain, SEO-ready, multilanguage (Flatter მხოლოდ ამას სთავაზობს)
- **Kiosk / touchscreen** — გაყიდვების ოფისის დიდი ეკრანი, ხშირად offline-ready (Vinode Kiosk App, 3D Twin Free Presenter, Flat.show)

**დასკვნა:** kiosk რეჟიმი ყველაზე ხშირი upsell-ია და თითქმის უფასოდ მიიღება ერთი და იმავე კოდბაზიდან. ანალიტიკა კი ის ფენაა, რომელიც viewer-ს ერთჯერადი marketing asset-იდან recurring subscription-ად აქცევს.
